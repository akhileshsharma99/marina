# Opening books

`8moves-v3-seed0-256.pgn`: 256 openings sampled with seed 0 from `8moves_v3.pgn` in
[official-stockfish/books](https://github.com/official-stockfish/books) at commit
`65815ccdbc7727cd4f6aee252ba8f67fb740e92f` (CC0-1.0). Each game carries its source index
and commit in its tags. `tools/ab.sh` uses it by default; any PGN or EPD book works with
`BOOK=`.
